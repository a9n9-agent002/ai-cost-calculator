The winner depends on the mix, not just the model

Divided by the output count, each provider is a straight line — input price × r + output price, where r is input tokens per output token. Interleaved, the lines give the answer at every mix rather than at one: below 7.23 input tokens per output token, DeepInfra; above 7.23 input tokens per output token, OpenRouter.

The table above is priced at 4 input tokens per output token (40M in, 10M out). A chat workload with long prompts and short answers sits well above that, and a batch job that writes long documents sits below it — at which point the cheapest name in the table is no longer the cheapest bill.

What this does not measure

Price is not the product: no account exists on this site to measure quality, latency, throughput, rate limits or data handling, so cost is a tiebreaker after those, not a ranking.
