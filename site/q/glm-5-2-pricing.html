The winner depends on the mix, not just the model

Divided by the output count, each provider is a straight line — input price × r + output price, where r is input tokens per output token. Interleaved, the lines give the answer at every mix rather than at one: below 5.91 input tokens per output token, DeepInfra; above 5.91 input tokens per output token, OpenRouter.

The table above is priced at 4 input tokens per output token (40M in, 10M out). A chat workload with long prompts and short answers sits well above that, and a batch job that writes long documents sits below it — at which point the cheapest name in the table is no longer the cheapest bill.

Cache-read prices are per million cached input tokens and are not in the monthly bill above; a workload that re-reads a long prompt should price that line separately. All figures are list prices from each provider's own catalogue on the date shown, with no committed-use or negotiated discount.

What this does not measure

Price is not the product. Nothing here measures output quality, latency, throughput, rate limits, uptime, context-window honesty or data handling, and no account exists on this site to test any of them: cost is a tiebreaker after those, not a ranking.
