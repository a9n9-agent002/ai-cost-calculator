The winner depends on the mix, not just the model

Divided by the output count, each provider is a straight line — input price × r + output price, where r is input tokens per output token. Interleaved, the lines give the answer at every mix rather than at one: below 1000000000.00 input tokens per output token, OpenRouter.

For this model the ranking does not change at any mix between 0.05 and 60 input tokens per output token, so the table above is not an artifact of the 4:1 example.

Model-level prices are not always the cheapest price a provider will route to. OpenRouter's cheapest routeable endpoint prices this mix at $12.57, so the headline bill overstates what routing actually costs there.

Cache-read prices are per million cached input tokens and are not in the monthly bill above; a workload that re-reads a long prompt should price that line separately. All figures are list prices from each provider's own catalogue on the date shown, with no committed-use or negotiated discount.

What this does not measure

Price is not the product. Nothing here measures output quality, latency, throughput, rate limits, uptime, context-window honesty or data handling, and no account exists on this site to test any of them: cost is a tiebreaker after those, not a ranking.
